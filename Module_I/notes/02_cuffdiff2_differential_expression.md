# Module I — Differential Expression Analysis with Cuffdiff2

## 1. Objective

Compare gene and isoform expression between **1-month** and **4-month** mouse hippocampus RNA-seq samples using **Cuffdiff2 v2.2.1**, following the Johns Hopkins University transcriptomics course.

Cuffdiff2 uses aligned reads (BAM) and a transcript annotation (GTF) to estimate abundance and test differential expression. The comparison here is **Month 4 versus Month 1**: a positive log2 fold change indicates higher expression at 4 months.

## 2. Input samples

| Condition | Sample IDs | Replicates |
|---|---|---:|
| Month 1 (control) | SRR3734796, SRR3734797, SRR3734798 | 3 |
| Month 4 (test) | SRR3734820, SRR3734824, SRR3734825 | 3 |

**Input files:** coordinate-sorted BAMs generated by STAR (`results/STAR/BAM/`) and the PsiCLASS-derived annotated GTF (`results/PsiCLASS/WithGeneNames/psiclass_vote.withStrand.gtf`).

**Output directory:** `results/Cuffdiff/`, linked to the D: drive via `Module_I/results`.

**Workflow scripts:** `scripts/09_run_cuffdiff.sh` and `scripts/10_summarize_cuffdiff.sh`.

## 3. Cuffdiff2 command

The course command was adapted to local paths and two threads:

```bash
cuffdiff \
    -o "$WORKDIR" \
    -p 2 \
    "$ANNOT" \
    "$CTRLBAMS" \
    "$TESTBAMS" \
    &> "${WORKDIR}/cuffdiff.log"
```

| Argument | Meaning |
|---|---|
| `-o` | Output directory |
| `-p 2` | Use two threads |
| `"$ANNOT"` | PsiCLASS transcript annotation GTF |
| `"$CTRLBAMS"` | Comma-separated BAM files from Month 1 |
| `"$TESTBAMS"` | Comma-separated BAM files from Month 4 |
| `&>` | Redirect standard output and errors to the log |

**Bash syntax note:** the backslash (`\`) must be the very last character of a continued line; spaces or comments after it break line continuation.

Monitor the run with:

```bash
tail -f results/Cuffdiff/cuffdiff.log
pgrep -af cuffdiff
```

## 4. Understanding `gene_exp.diff`

The header of the generated file was checked with:

```bash
head -n 1 results/Cuffdiff/gene_exp.diff | tr '\t' '\n' | nl -ba
```

The actual file contains the following **14 columns**:

| # | Column | Description |
|---:|---|---|
| 1 | `test_id` | Internal identifier of the test |
| 2 | `gene_id` | Gene identifier |
| 3 | `gene` | Annotated gene name |
| 4 | `locus` | Genomic coordinates |
| 5 | `sample_1` | First condition (`q1` = Month 1, according to input order) |
| 6 | `sample_2` | Second condition (`q2` = Month 4, according to input order) |
| 7 | `status` | Test status (`OK`, `NOTEST`, `HIDATA`) |
| 8 | `value_1` | Estimated abundance in condition 1 |
| 9 | `value_2` | Estimated abundance in condition 2 |
| 10 | `log2(fold_change)` | Log2 ratio, Month 4 / Month 1 |
| 11 | `test_stat` | Test statistic |
| 12 | `p_value` | Unadjusted p-value |
| 13 | `q_value` | Multiple-testing-adjusted significance value |
| 14 | `significant` | Cuffdiff2 significance flag (`yes`/`no`) |

**Interpretation:** `log2FC > 0` means higher expression at 4 months; `log2FC < 0` means lower expression at 4 months. A log2FC of +1 is a twofold increase, and −1 is a twofold decrease.

## 6. Filtering differential expression with Bash

The following commands use the **verified column positions in this dataset**. Run them from `results/Cuffdiff/`.

### 6.1 Significant genes (Cuffdiff2 flag)

```bash
awk -F '\t' '$14 == "yes"' gene_exp.diff | wc -l
```

**Observed: 265 significant gene records.**

### 6.2 Upregulated genes (Month 4 > Month 1)

```bash
awk -F '\t' '$14 == "yes" && $10 > 0' gene_exp.diff | wc -l
```

**Observed: 63.**

### 6.3 Downregulated genes (Month 4 < Month 1)

```bash
awk -F '\t' '$14 == "yes" && $10 < 0' gene_exp.diff | wc -l
```

**Observed: 202.** The two directions add up to 265.

### 6.4 Alternative filter: p-value < 0.05 and |log2FC| > 0.5

```bash
awk -F '\t' '$7 == "OK" && ($10 < -0.5 || $10 > 0.5) && $12 < 0.05' gene_exp.diff | wc -l
```

**Observed: 507** using the corresponding filter without the explicit status condition; verify the count if adding `status == "OK"` changes it.

### 6.5 Alternative filter: p-value < 0.05 and |log2FC| > 1

```bash
awk -F '\t' '$7 == "OK" && ($10 < -1 || $10 > 1) && $12 < 0.05' gene_exp.diff | wc -l
```

**Observed: 131** using the corresponding filter without the explicit status condition; verify the count if adding `status == "OK"` changes it.

**Bash operators:** `$10` means column 10 in `awk`; `&&` means AND; `||` means OR; `$0` represents the entire line; `wc -l` counts lines. `-F '\t'` specifies a tab delimiter.

**Statistical caution:** filters based on unadjusted `p_value < 0.05` are exploratory and are **not equivalent to FDR-significant results** based on `q_value`/`significant`.

## 10. Limitations and next steps

- The groups differ in age, but their **sex composition may also differ**. The differential expression of `Xist`, an X-chromosome-associated gene, is a reason to investigate this potential confounder before attributing results exclusively to age.
- These are **gene and isoform abundance comparisons**, not direct evidence of causation or a comprehensive analysis of differential transcript usage.
- Review metadata, confirm any filtering of the GTF, and compare with **DESeq2** after generating an appropriate gene-level raw count matrix.
- Keep software versions, input GTF, BAM sample order, parameters, and result summaries documented for reproducibility.

## Key concepts

**Differential expression:** statistical assessment of expression differences between conditions.  
**log2FoldChange:** log2 ratio of estimated expression (Month 4 / Month 1).  
**p-value:** unadjusted statistical evidence under the null hypothesis.  
**q-value / FDR:** multiple-testing-adjusted measure used to limit false discoveries.  
**Isoform:** a transcript variant associated with a gene.  
**Replicate:** an independent sample representing the same experimental condition.
